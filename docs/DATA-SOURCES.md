# 数据源与口径

全部数据来自公开接口，在本机环境（经 HTTP 代理出网）逐个实测过
可用性。这一页记录的是实测结论与坑，而不是接口文档的转述。

## 主力数据源

| 数据 | 来源 | 说明 |
| --- | --- | --- |
| 全市场快照 | 新浪 Market_Center | 粗筛与落盘用；涨跌幅字段有已知错值（见下） |
| 个股报价/日K | 腾讯 qt.gtimg / web.ifzq | 前复权日K；总市值在字段 45、换手率在字段 43 |
| 涨停/跌停池 | 东方财富 push2ex | 涨停筛选以涨停池 + 日K收盘涨幅复核为准 |
| 竞价全市场 | 新浪 + 东财 82.push2 + 腾讯探活 | 三通道竞速，实测全量约 23 秒、零缺失 |
| 开盘啦数据 | 开盘啦 App 公开接口 | 板块强度、涨停原因、情绪分布、复盘啦等；公开参数即可读 |
| 外围行情 | 新浪 hf_ 期货代码 / Yahoo Finance | 日经/纳指/A50/黄金/原油期货 + 日韩指数 |
| 消息面 | 财联社、东方财富、巨潮资讯等 | 公告与新闻核查 |

不可用（本机环境）：BaoStock 直连 TCP、东方财富 push2/push2his 主站。

## 已知坑（实测）

- **新浪快照涨跌幅有错值**：曾出现单日 44 只股票的快照涨跌幅与
  实际收盘不符，且快照名称会剥掉 ST 前缀。用快照筛涨停会误报；
  ST 判断必须用腾讯名称，涨停必须用涨停池 + 日K复核。
- **腾讯简版指数报价会返回陈旧值**：指数必须用完整版报价，
  涨跌幅以现价/昨收自算。
- **腾讯前复权日K并发上限**：并发 ≥20 大量失败，且失败回退到
  不复权数据会让均线判定翻转；批量跑批并发 ≤5，争议票单源串行定版。
- **竞价数据不可补**：免费源不存历史竞价量，日K也无竞价量字段；
  竞价量/额只能 09:25 当场抓取定格，全市场只剔 ST 全量落盘。
- **开盘啦板块强度要分页**：精选板块共 200 多个，每页 50 条翻页拉全；
  只拉第一页会让「最弱板块」完全错误。单页条数超过 100 会异常回退。
- **新浪 int_nikkei 是陈旧假值**，与实况差上万点，禁用；
  日经用期货代码 hf_NK。

## 口径约定

- 收盘数据只认 15:00 收盘：指数点位、收盘家数、涨跌停数、
  全天成交、个股收盘价；盘中过程数字单独标注时点。
- 涨停按板块幅度收盘口径：主板 ≥9.8%、双创 ≥19.7%。
- 市值按选股时点最新总市值现算（腾讯字段 45）。
- 盘中盯盘取数走摘要脚本（全市场快照压成约 2KB 摘要），
  不把全量快照读进分析上下文。
