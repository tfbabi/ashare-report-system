# 工具代码

系统自研的取数与加工脚本（Python），均为实测在用的版本。
脚本从命令行运行，数据落盘在各自的工作目录；细节见各文件头部注释。

| 脚本 | 用途 |
| --- | --- |
| `auction_fetch.py` | 竞价三通道竞速抓取：腾讯探活快弃 + 新浪全市场 + 东财 clist，09:25 定格全市场竞价快照 |
| `auction_vol_screen.py` | 竞价放量筛选器：竞价额较昨日放量分档机械筛选（小额档/大额档），输出标准列名单表 |
| `intraday_vol_screen.py` | 成交放量筛选器：盘中放量 + 站上分时黄线与 5 日线的走强筛选 |
| `table_fields.py` | 名单标准字段计算器：开盘涨幅、较昨日放量、黄均线、图形形态、连涨天数、市值一次算齐 |
| `intraday_digest.py` | 盘中摘要：全市场快照 + 外围联动压成约 2KB 摘要，供盘中各趟快速研判 |
| `local_store.py` | 本地行情存储：快照/日K 的落盘与读取约定 |
| `md_to_html_email.py` | 报告 Markdown → HTML 转换器：四线横幅配色、百分比红绿着色、股票链接挂载、表格规范化，全部交付共用 |

说明：这些脚本是为特定数据源与本机网络环境调通的，使用前请先读
[数据源与口径](../docs/DATA-SOURCES.md)里的实测坑。
